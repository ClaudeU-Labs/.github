# ClaudeU Labs

面向 Windows AI 桌面工作流的独立工具、诊断与实用指南。我们开放可独立复用的工具和知识，ClaudeU Desktop 商业产品本体不在这些仓库的开源许可范围内。

Independent tools, diagnostics, and practical guides for Windows AI desktop workflows. We open-source reusable tools and knowledge; the proprietary ClaudeU Desktop product is not covered by these repositories' open licenses.

## 从这里开始 · Start here

| 仓库 · Repository | 解决的问题 · What it solves | 适合谁 · For whom |
| --- | --- | --- |
| [claude-desktop-doctor](https://github.com/ClaudeU-Labs/claude-desktop-doctor) | 本地、只读、默认脱敏的 Windows 环境与配置诊断 · Local, read-only, redacted-by-default Windows environment and configuration diagnostics | 遇到安装、配置、网络或 MCP 问题的用户 · Users troubleshooting installation, configuration, connectivity, or MCP |
| [claude-desktop-windows-guide](https://github.com/ClaudeU-Labs/claude-desktop-windows-guide) | 中文优先的 Windows 安装、配置、连接与排障指南 · Chinese-first Windows installation, configuration, connectivity, and troubleshooting guide | 希望从零跑通 Windows 工作流的用户 · Users setting up a Windows workflow from scratch |
| [claude-mcp-starter-cn](https://github.com/ClaudeU-Labs/claude-mcp-starter-cn) | 可解析配置模板、离线静态检查与中文 MCP 排障资料 · Parseable templates, offline static checks, and Chinese MCP troubleshooting material | 需要安全配置和检查 MCP 的 Windows 用户 · Windows users configuring and checking MCP safely |

这些仓库只解决各自 README 明确列出的公开问题。它们不包含 ClaudeU Desktop、商业安装器、账户服务、网关、计费系统或商业运行时集成。

Each repository covers only the public scope stated in its README. None includes ClaudeU Desktop, the commercial installer, account services, gateway, billing system, or commercial runtime integrations.

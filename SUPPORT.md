# Support · 支持分流

请选择与问题性质匹配的入口。这能避免把账号或敏感信息放进公开 Issue，也能让公开仓库保持可检索的技术内容。

Choose the route that matches your issue. This keeps account data out of public issues and preserves useful, searchable technical discussions.

| 问题 · Question | 入口 · Where to go |
| --- | --- |
| 公开工具的缺陷、文档错误、兼容矩阵修正 · Bug in a public tool, documentation error, or compatibility correction | 对应仓库的 Issue · The affected repository's issue tracker |
| 公开工具的功能建议 · Feature request for a public tool | 对应仓库的 Issue，说明用户场景和边界 · The affected repository's issue tracker with the user scenario and scope |
| ClaudeU Desktop 安装、账户、支付、额度、网关或商业服务 · ClaudeU Desktop installation, account, payment, quota, gateway, or commercial service | 通过 [ClaudeU 产品首页](https://claudeu.com/?utm_source=github&utm_medium=organic&utm_campaign=claudeu-labs&utm_content=support-routing) 进入当前联系入口 · Use the current contact route from the ClaudeU homepage |
| 安全漏洞或敏感数据暴露 · Vulnerability or sensitive-data exposure | 按 [SECURITY.md](SECURITY.md) 私下报告 · Report privately under [SECURITY.md](SECURITY.md) |
| Anthropic 产品或服务问题 · Anthropic product or service question | Anthropic 的官方支持渠道 · Anthropic's official support channels |

## Public issue checklist

Before opening a public issue:

- search for existing reports;
- reproduce on the latest supported version when practical;
- include expected and actual behavior;
- use synthetic examples;
- redact usernames, local paths, IP addresses, machine identifiers, request identifiers, account identifiers, tokens, cookies, and credentials;
- do not attach official binaries, installers, runtimes, `app.asar`, user profiles, or raw diagnostic bundles.

The public repositories do not provide support for bypassing account, payment, subscription, regional-availability, access-control, integrity, update, or service-policy requirements.
